# 珍獣ショーダウン

珍獣の対戦ゲーム「珍獣ショーダウン」。ハシビロコウ、ラーテル、ダイオウグソクムシ…世界の珍獣80種類以上で戦う、ブラウザのバトルロイヤルゲームです。

▶ **遊ぶ**：https://chinju-showdown.github.io/chinju/

📝 **最新バージョン**：1.23.0（2026/11/8）　→ [更新履歴](CHANGELOG.md)

𝕏 **公式X**：[@chinju_showdown](https://x.com/chinju_showdown)（新しい珍獣やアップデートのお知らせ）

## 👪 おうちの方へ

- **対象年齢**：7歳以上（小学1〜2年生は、おうちの人と一緒に遊ぶのがおすすめです）
- **課金なし**：お金を払うしくみはありません。ガチャはゲーム内のクレジットだけで回せます。
- **知らない人とつながらない**：チャット機能はありません。2人対戦は、同じWi-Fiにいる目の前の相手とQRコードを読みあって遊ぶ形です。
- **個人情報を集めません**：アカウント登録はなく、遊んだ記録はその端末の中だけに保存されます。ゲームをよくするために、人気の珍獣やよく遊ばれるモードなど「遊ばれた回数」だけを [GoatCounter](https://www.goatcounter.com/)（Cookieを使わない集計サービス）で数えています。名前・セーブコード・受付番号・暗証番号・場所は送りません。設定の「遊ばれ方のデータ」でオフにできます。
- **遊ぶ時間のきまり**：設定から、おうちの人が4けたの暗証番号で1日に遊べる時間（15〜120分）と期間を決められます。
- **表現**：動物のキャラクターがアニメ調で戦います。血や残酷な表現はありません。
- **外部リンク**：設定に公式X（13歳以上向けのサービス）とGoogleフォーム（報告用・名前は書かない形）へのリンクがあります。

## できること

- ソロバトル（10頭のバトルロイヤル）
- ボス戦（四神と両面宿儺）・ガチバトル（ランク戦）・古代祭
- ちびペット冒険記：卵から育てるペットのRPG
- 2人で遊ぶ：スマホどうしで直接対戦（サーバーなし）
- マップ作り・珍獣図鑑・称号200個・リプレイ
- 日本語 / English / 한국어 / 中文（简体） / 中文（繁體） / Español / Português / Bahasa Indonesia / Tiếng Việt / ภาษาไทย

## 遊び方

スマホやパソコンのブラウザで開くだけで遊べます。ホーム画面に追加すると、アプリのように全画面で遊べます。

遊んだ記録はその端末に保存されます。別の端末へは、設定の「セーブコード」で引っ越せます。
