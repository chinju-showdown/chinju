# 珍獣ショーダウン

珍獣の対戦ゲーム「珍獣ショーダウン」。ハシビロコウ、ラーテル、ダイオウグソクムシ…世界の珍獣80種類以上で戦う、ブラウザのバトルロイヤルゲームです。

▶ **遊ぶ**：https://chinju-showdown.github.io/chinju/

## できること

- ソロバトル（10頭のバトルロイヤル）
- ボス戦（四神と両面宿儺）・ガチバトル（ランク戦）・古代祭
- ちびペット冒険記：卵から育てるペットのRPG
- 2人で遊ぶ：スマホどうしで直接対戦（サーバーなし）
- マップ作り・珍獣図鑑・称号101個・リプレイ
- 日本語 / English / 한국어 / 中文

## 遊び方

スマホやパソコンのブラウザで開くだけで遊べます。ホーム画面に追加すると、アプリのように全画面で遊べます。

遊んだ記録はその端末に保存されます。別の端末へは、設定の「セーブコード」で引っ越せます。
